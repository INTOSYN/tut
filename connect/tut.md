# 客户端使用指南


## 1. 注册账户

打开 [AI4Sci 注册页面](https://www.ai4sci.uk/auth/register)，填写：

- 昵称
- 邮箱
- 密码和确认密码
- 邀请码（必填）

同意服务条款后点击 **Create Account**。已有账户可直接打开 [登录页面](https://www.ai4sci.uk/auth/login)。

## 2. 下载客户端

登录网站后进入用户文档，查看app教程

## 3. 连接 GPU 服务器

确认客户端中存在 `A100-Drive-4` 组，然后连接分配给你的服务器：

```bash
ssh ubuntu@ip
ssh ubuntu@ip
```

入口都使用 SSH 默认端口 `22`
